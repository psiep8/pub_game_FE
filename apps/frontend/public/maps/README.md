# Cartine dei paesi

Le sagome in questa cartella vengono da [Mapsicon](https://github.com/djaiss/mapsicon)
di djaiss, usate secondo la licenza del progetto: libero utilizzo con menzione
dell'autore, senza rivendita. Le immagini sono segnaposto geografici, non carte
precise.

Sono caricate solo quando la TV mostra una manche Paesi di Azzardo. Se una
sagoma manca, la TV usa la bandiera da Flagcdn.
